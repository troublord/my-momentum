# MyMomentum 登入系統說明

## 概述

MyMomentum 專案採用 Google OAuth 2.0 作為主要登入方式，結合 JWT (JSON Web Token) 進行身份驗證和授權管理。

## 技術架構

### 前端技術棧

- **React 18** + **TypeScript**
- **React Router** 用於路由管理
- **@react-oauth/google** 用於 Google OAuth 整合
- **jwt-decode** 用於 JWT token 解析
- **Context API** 用於全域狀態管理

### 後端 API

- **Base URL**: `http://localhost:8080`
- **認證端點**: `/auth/google`

## 登入流程詳解

### 1. 應用程式初始化

```typescript
// src/index.tsx
<GoogleOAuthProvider clientId="861849830529-44mlejpcr9jjhh19qbvib8vjfbo42gea.apps.googleusercontent.com">
  <AuthProvider>
    <App />
  </AuthProvider>
</GoogleOAuthProvider>
```

### 2. 認證狀態管理 (AuthContext)

```typescript
// src/contexts/AuthContext.tsx
- accessToken: string | null  // JWT token
- isAuthenticated: boolean    // 登入狀態
- setAccessToken: function    // 設定 token
- logout: function           // 登出功能
```

**核心功能：**

- **自動登入檢查**: 應用啟動時檢查 localStorage 中的 token
- **Token 過期驗證**: 使用 jwt-decode 檢查 token 是否過期
- **自動清理**: 過期或無效的 token 會被自動移除
- **狀態同步**: token 變更時同步更新 localStorage

### 3. Google OAuth 登入流程

#### 步驟 1: 用戶點擊登入

```typescript
// src/components/IntroPage.tsx
<GoogleLogin
  onSuccess={(credentialResponse) => {
    handleGoogleCredential(credentialResponse.credential);
  }}
  onError={() => {
    setError("登入失敗，請稍後再試");
  }}
/>
```

#### 步驟 2: 處理 Google 憑證

```typescript
const handleGoogleCredential = async (credential?: string) => {
  if (!credential) {
    setError("未取得 Google 憑證");
    return;
  }

  try {
    setIsLoading(true);
    setError(null);
    // 發送 idToken 到後端驗證
    const { accessToken } = await authenticateWithGoogle(credential);
    setAccessToken(accessToken);
  } catch (e) {
    setError("登入失敗，請稍後再試");
  } finally {
    setIsLoading(false);
  }
};
```

#### 步驟 3: 後端驗證

```typescript
// src/services/auth.ts
export const authenticateWithGoogle = async (
  idToken: string
): Promise<AuthResponse> => {
  const response = await fetch(`${API_BASE}/auth/google`, {
    method: "POST",
    headers: {
      "Content-Type": "application/json",
    },
    body: JSON.stringify({ idToken }),
  });

  if (!response.ok) {
    throw new Error(`Auth failed with status ${response.status}`);
  }

  return response.json();
};
```

### 4. 認證狀態檢查與路由保護

#### 主應用程式邏輯

```typescript
// src/App.tsx
const { isAuthenticated } = useAuth();

// 未登入時顯示登入頁面
if (!isAuthenticated) {
  return <IntroPage />;
}

// 已登入時顯示主應用程式
return (
  <div className="min-h-screen bg-gray-50">
    <Header />
    {/* 主要內容 */}
  </div>
);
```

### 5. API 請求認證

#### 自動添加 Authorization Header

```typescript
// src/services/api.ts
const headers: HeadersInit = useMemo(
  () => ({
    "Content-Type": "application/json",
    ...(accessToken ? { Authorization: `Bearer ${accessToken}` } : {}),
  }),
  [accessToken]
);
```

#### 認證錯誤處理

```typescript
const handleAuthError = useCallback(() => {
  logout();
  addError({
    type: "error",
    title: "登入已過期",
    message: "您的登入已過期，請重新登入",
    autoHide: true,
    autoHideDelay: 5000,
  });
}, [logout, addError]);
```

### 6. 登出流程

#### 用戶觸發登出

```typescript
// src/components/Header.tsx
const handleLogout = () => {
  logout();
};
```

#### 清理認證狀態

```typescript
// src/contexts/AuthContext.tsx
const logout = useCallback(() => {
  setAccessToken(null); // 清除 token 和 localStorage
}, [setAccessToken]);
```

## 安全特性

### 1. Token 管理

- **本地儲存**: 使用 localStorage 持久化 token
- **自動過期檢查**: 每次應用啟動時驗證 token 有效性
- **安全清理**: 無效或過期 token 自動移除

### 2. 錯誤處理

- **網路錯誤**: 顯示友善的錯誤訊息
- **認證失敗**: 自動登出並提示重新登入
- **API 錯誤**: 統一的錯誤處理機制

### 3. 狀態同步

- **Context 管理**: 全域認證狀態管理
- **自動更新**: token 變更時自動更新所有相關組件
- **記憶體優化**: 使用 useMemo 和 useCallback 優化效能

## 優點

1. **安全性高**: 使用 Google OAuth 2.0 標準
2. **用戶體驗佳**: 一鍵登入，無需記住密碼
3. **維護簡單**: 認證邏輯集中管理
4. **擴展性好**: 易於添加其他登入方式
5. **錯誤處理完善**: 全面的錯誤處理機制

## 注意事項

1. **Google Client ID**: 需要在 Google Cloud Console 設定
2. **後端驗證**: 需要後端實作 `/auth/google` 端點
3. **HTTPS**: 生產環境必須使用 HTTPS
4. **Token 過期**: 需要實作 refresh token 機制（目前未實作）
