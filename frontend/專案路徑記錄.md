# MyMomentum 專案路徑記錄

### 前端專案

- **路徑**: `C:\BausensLaw\MyMomentum\frontend`
- **技術棧**: React + TypeScript + TailwindCSS
- **主要功能**: 用戶界面、Google OAuth 登入、活動管理

### 後端專案

- **路徑**: `C:\BausensLaw\MyMomentum\backend\mymomentum`
- **API Base URL**: `http://localhost:8080`
- **主要端點**:

  - 其他業務 API 端點

## 開發注意事項

- 前端與後端需要同時運行才能完整測試功能
- 前端使用後端提供的 JWT token 進行 API 認證
- 後端負責驗證 Google ID Token 並生成自定義 JWT
